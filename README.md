This Java program implements a console-based Tic Tac Toe game for two players.
It uses a 3×3 grid represented by a 2D character array. 
Players take turns entering row and column positions to place their marks (X or O). 
The game checks for valid input, prevents overwriting moves, and determines if a player has won by checking rows, columns, and diagonals.
If all cells are filled without a winner, it declares a draw. After each game, players are prompted to play again. 
The board is displayed after every move with a clean visual layout using ASCII characters.
